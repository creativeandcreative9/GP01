# GP01 モールス信号練習アプリ

スマホ向けPWA(インストール不要、ホーム画面に追加で利用可)。

## 現在の機能
- 聞き取り練習: 音(ト・ツー)を再生し、対応する文字をタップで回答
- 視覚表示: モールス符号ツリー(点=左・線=右)上で、音に同期して経路が光り、回答後に正解の文字がオレンジで点灯。ト/ツーの文字も表示(ON/OFF可)
- 対象文字は英字A–Zのみ(数字は除外)
- 速度(WPM)・音の高さ・練習文字数(Koch法の習得順で段階的に増加)を設定可
- 正解数・連続正解の記録(端末内に保存)、オフライン動作

## 動かし方
`python3 -m http.server` などで配信し、ブラウザで開く。ES Modulesを使うため `file://` では不可。
