# GP01 モールス信号練習アプリ

スマホ向けPWA(インストール不要、ホーム画面に追加で利用可)。

## 現在の機能
- 聞き取り練習: 音(ト・ツー)を再生し、対応する文字をタップで回答
- 視覚表示: モールス符号ツリー(点=左・線=右)上で、音に同期して経路が光り、回答後に正解の文字がオレンジで点灯。ト/ツーの文字も表示(ON/OFF可)
- 対象文字は英字A–Zのみ(数字は除外)
- 打鍵モード: 画面の打鍵ボタン(PCはスペースキー)を短く押すと「ト」、長押しで「ツー」。入力がツリーに光り、無入力が続くと1文字として判定
- フリー打鍵モード: 目標なしで自由に打鍵。間をあけると文字として確定(英字・数字を判定、不明は「?」)、さらに長い間で自動的にスペース。スペース・1文字消す(PCはBackspace)・全消去ボタン付き
- 聞き取り中級モード(FLOW): 100個のフレーズを#1(HELLO WORLD)から順に再生して聞き取り、打鍵で再現する。字数分だけ打鍵すると自動で正誤判定(OK/NG、正解数・連続正解に反映)。判定前は「_」で字数だけ表示し、答えは見せない。もう一度聞く・次へ(聞き直しは入力を保持、判定前に次へ進むと飛ばせる)操作可。位置は端末内に保存し、続きから再開できる
- 聞き取り上級モード(MUSE): 100個のフレーズを#1から#100まで順番に再生して聞き取る。再生後に全文が表示され、一定時間後に自動で次へ。前へ・もう一度・一時停止・次へ操作可。聞き終えた分は履歴に並び、続きから再開できる(端末内に保存)
- 練習ステップ(設定): ステップ1 K,M → 2 +R → 3 +S → 4 +I → 5 +A → 6 +P → 7 +T → 8 +L → 9 +O。初期値は従来の「標準(文字数スライダー)」
- 速度(WPM)・音の高さ・練習文字数(Koch法の習得順で段階的に増加)を設定可
- 正解数・連続正解の記録(端末内に保存)、オフライン動作

## 動かし方
`python3 -m http.server` などで配信し、ブラウザで開く。ES Modulesを使うため `file://` では不可。
